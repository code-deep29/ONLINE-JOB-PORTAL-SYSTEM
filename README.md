🚀 JobFinder Portal - Online Job Portal System

Welcome to the **JobFinder Portal** repository! This is a web-based Job Portal System (similar to Naukri.com) designed to connect job seekers with recruiters.

This project was developed as a **Mini Project for B.Tech 2nd Year (3rd Semester)**.

📖 Project Overview
**JobFinder** acts as a bridge between professionals looking for jobs and companies looking for talent. The interface is designed to be clean, responsive, and user-friendly.

✨ Key Features
- **Responsive Design:** Works on Mobile, Tablet, and Desktop.
- **Job Search Module:** Users can search jobs by Role and Location.
- **Job Listings:** Grid layout displaying Featured Jobs with details (Salary, Location, Experience).
- **Interactive UI:** Login Overlay popup and hover effects using CSS.
- **Frontend Only:** Built using pure HTML, CSS, and JavaScript (No external frameworks).

---

🛠️ Tech Stack Used
- **Frontend:** HTML5, CSS3
- **Scripting:** JavaScript (Vanilla JS)
- **Editor:** VS Code
- **Fonts:** Google Fonts (Poppins)
